# Licenca Pendente de Decisao

Este projeto ainda nao tem uma licenca definitiva escolhida.

Nenhum termo legal final deve ser assumido ate que o mantenedor confirme a licenca desejada.

Opcoes comuns para avaliar:

- **MIT**: permissiva, simples, adequada quando a intencao e permitir reuso amplo de codigo.
- **CC-BY-NC-SA**: mais restritiva, comum para conteudo criativo quando a intencao e exigir atribuicao, uso nao comercial e compartilhamento pela mesma licenca.

Pendencia: decidir se o projeto deve separar licenca de codigo, assets, textos, quests e documentacao.
