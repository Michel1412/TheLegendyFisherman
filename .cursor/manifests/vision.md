# TLF Vision Refactor

> Fonte da verdade para a visao de produto, arquitetura e progressao do modpack **The Legendary Fishman**.

---

## Como usar este documento

Preencha este arquivo antes de iniciar refatoracoes de sistemas, quests, economia, progressao ou curadoria de mods.

- Use `TBD` para decisoes ainda abertas.
- Registre decisoes firmes como texto direto, nao como brainstorm.
- Quando uma secao mudar uma decisao tecnica, atualize tambem os documentos relacionados em `.cursor/internal-docs/` ou `.cursor/architecture/`.
